# Security

The script runs on your own machine, asks for Administrator rights through UAC, and loads a small compiled helper into RDCMan to recolour its window. It doesn't connect to the internet and doesn't read your RDCMan server list, credentials or remote sessions.

If you find a security problem, such as a way for another user or program to get code run through the script or the helper, please don't open a public issue. Report it privately with GitHub's [private vulnerability reporting](../../security/advisories/new) instead. You'll get an answer as soon as the maintainer can look at it.
